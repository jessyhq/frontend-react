# jessy
jessy is a modular webapp that helps students study, available at [jessy.app](https://jessy.app).

## Features
1. Timer: WIP
2. Full fledged Evernote/Notion type notes.
3. Google Keep type stickies.
4. Subject live chat
5. Spotify/Youtube support. Or upload music files and play them: DONE
6. Extension to block social media websites.
7. Tasks: DONE
